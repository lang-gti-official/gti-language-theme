INTRODUCTION                                      *gti_theme.nvim-introduction*

GTI Theme provides one dark palette for GTI and other source languages.

Lua module: >
    require("gti_theme")
<
Colorscheme: >
    :colorscheme gti
<
Loading the colorscheme sets 'background' to "dark". There are no palette
variants or compatibility colorscheme names.

==============================================================================
INSTALLATION                                       *gti_theme.nvim-installation*

lazy.nvim: >lua
    {
      "lang-gti-official/gti-language-theme",
      lazy = false,
      priority = 1000,
      opts = {},
      config = function(_, opts)
        require("gti_theme").setup(opts)
        vim.cmd.colorscheme("gti")
      end,
    }
<

==============================================================================
CONFIGURATION                                     *gti_theme.nvim-configuration*

Call setup() before loading the colorscheme: >lua
    require("gti_theme").setup({
      transparent = false,
      terminal_colors = true,
      styles = {
        comments = { italic = true },
        keywords = { italic = true },
        functions = {},
        variables = {},
        sidebars = "dark",
        floats = "dark",
      },
      dim_inactive = false,
      lualine_bold = false,
      cache = true,
      plugins = {
        all = false,
        auto = true,
      },
      on_colors = function(colors) end,
      on_highlights = function(highlights, colors) end,
    })
<
`on_colors` runs after derived colors are built and before highlight groups are
created. `on_highlights` receives the final merged highlight table.

==============================================================================
GTI HIGHLIGHTING                                             *gti_theme.nvim-gti*

GTI-specific presentation links are defined in:

    lua/gti_theme/groups/gti.lua

They adapt high-priority GTI semantic-token combinations to the final groups
used by equivalent C++ constructs. Shared palette, Tree-sitter, and generic LSP
groups are not changed for this adaptation.

Readonly GTI parameters, for example, link to `@variable.parameter`, while
readonly local variables link to `@variable`.

==============================================================================
INTEGRATIONS                                         *gti_theme.nvim-integrations*

Lualine: >lua
    require("lualine").setup({ options = { theme = "gti" } })
<
Lightline: >vim
    let g:lightline = { 'colorscheme': 'gti' }
<
Barbecue: >lua
    require("barbecue").setup({ theme = "gti" })
<
Plugin highlights are enabled automatically with lazy.nvim, all together with
`plugins.all = true`, or individually through the `plugins` configuration.

GTI-only exports for supported terminals and tools are stored under
`extras/` and generated by `./scripts/build`.
